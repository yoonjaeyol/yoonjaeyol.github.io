개요

OpenClaw-Gmail은 윤재열(Jaeyol Yoon)이 개인 용도로만 운영하는 Google Cloud 프로젝트의 OAuth 앱입니다. 소유자의 개인 서버에서 실행되는 개인 AI 비서(Hermes agent)가 소유자 본인의 Google 계정에 접근하여 소유자의 작업을 자동화합니다. 공개 서비스가 아니며 소유자 외의 사용자는 없습니다.

수집·이용하는 정보

소유자 본인의 Google 계정에 대해 다음 Google API 범위에 접근합니다.

  • Gmail (읽기, 보내기, 수정)
  • Google Calendar
  • Google Drive
  • Google Contacts
  • Google Sheets
  • Google Docs
  • Google Slides
  • Google Tasks

이용 목적

소유자가 요청한 작업(예: 메일 읽기·보내기, 캘린더 일정 관리, Drive 파일 정리, Docs/Sheets/Slides 편집, Tasks, 연락처 관리)을 수행하는 데에만 사용합니다. 소유자만 사용하며 다른 사용자는 없습니다. 판매, 광고, AI/ML 모델 학습에 사용하지 않습니다.

Google API에서 받은 정보의 사용 및 전송은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

보관·보안

OAuth 토큰은 소유자의 개인 서버에만 저장되며, 소유자만 읽을 수 있는 파일(권한 600)에 보관됩니다. Google 데이터는 저장하지 않으며, 요청된 작업에 필요한 임시 작업 사본만 생성 후 삭제합니다(임시 파일은 24시간 이내 자동 삭제).

제3자 제공

Google 사용자 데이터를 제3자에게 판매하거나 제공·공유하지 않습니다.

철회

접근 권한은 언제든지 https://myaccount.google.com/permissions에서 철회할 수 있습니다.

Privacy Policy

Overview

OpenClaw-Gmail is an OAuth app in a personal Google Cloud project, operated by Jaeyol Yoon (윤재열), an individual, for personal use only. It lets the owner's personal AI assistant (Hermes agent), running on the owner's own server, access the owner's own Google accounts to automate the owner's tasks. It is not a public product and has no users other than the owner.

Data accessed

The app accesses the following Google API scopes on the owner's own Google accounts:

  • Gmail (read, send, modify)
  • Google Calendar
  • Google Drive
  • Google Contacts
  • Google Sheets
  • Google Docs
  • Google Slides
  • Google Tasks

Use

Data is used only to perform tasks the owner requests (e.g. reading/sending the owner's mail, calendar events, organizing Drive files, editing the owner's Docs/Sheets/Slides, Tasks, Contacts). It is used only by the owner; there are no other users. Data is not sold, not used for advertising, and not used for training AI/ML models.

The use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Storage & security

OAuth tokens are stored only on the owner's private server, in a file readable only by the owner (permission 600). Google data is not stored, except for temporary working copies needed for a requested task, which are deleted afterwards (scratch files are auto-pruned within 24 hours).

Sharing

Google user data is not sold to, shared with, or transferred to any third party.

Revocation

Access can be revoked at any time at https://myaccount.google.com/permissions.
